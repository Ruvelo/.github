**Ruvelo builds open-source extensions for the platforms you already run: Laravel, WordPress and Magento.**

Every Ruvelo package installs in one command, works without a build step, and comes with typed APIs, real docs and a live demo. Clean enough for your users, solid enough for your codebase.

### Projects

| | |
|---|---|
| **[Laravel Wiki](https://github.com/Ruvelo/laravel-wiki)** | A drop-in wiki for your Laravel app: Markdown pages, `[[links]]`, full history, a JSON API and Obsidian import. [Live demo](https://ruvelo.github.io/laravel-wiki/demo/) |

### Contributing

Issues and pull requests are welcome on every repo. Each has a `CONTRIBUTING.md`, and `composer check` runs exactly what CI runs. Please read the [code of conduct](https://github.com/Ruvelo/.github/blob/main/CODE_OF_CONDUCT.md).
