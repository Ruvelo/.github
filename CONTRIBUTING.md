# Contributing to Ruvelo projects

Thanks for helping! Each project has its own `CONTRIBUTING.md` with setup steps; this is the shared baseline.

1. **Small fixes:** go straight to a pull request.
2. **Bigger changes:** open an issue first so we can agree on the approach.
3. **Every PR:** includes a test, passes `composer check` (code style, static analysis and tests), and adds a line to `CHANGELOG.md` under *Unreleased*.
4. **Visual changes:** follow the [house style](BRAND.md) and add a screenshot to the PR.

By contributing you agree your work is released under the project's license and that you'll follow the [code of conduct](CODE_OF_CONDUCT.md).
