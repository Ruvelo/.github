# Security policy

## Reporting a vulnerability

**Please don't open a public issue.** Use the repository's **Security → Report a vulnerability** form instead. It creates a private advisory that only the maintainers can see.

Tell us what you found, how to reproduce it, and which versions are affected. We'll confirm receipt within three working days, keep you posted on the fix, and credit you in the release notes unless you'd rather we didn't.

## Supported versions

Security fixes go into the latest minor release of each package. Upgrade to the newest version to get them.
